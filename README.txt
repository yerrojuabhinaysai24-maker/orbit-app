ORBIT V7 — Premium News Feed Test Build

Changes from V6:
- One-story-at-a-time reels-style feed retained.
- Much stronger article image selection: media:content, media:thumbnail, enclosures, embedded RSS images, srcset, and high-resolution URL variants are ranked before display.
- If the first image fails, ORBIT automatically tries the next available publisher image.
- No AI-generated news images.
- If the publisher provides no usable image, ORBIT shows a branded visual fallback instead of a black/empty block.
- News summaries are now built from the feed's actual description/content and shown prominently under a small IN BRIEF label.
- Image area and text treatment are closer to the approved ORBIT mockup.
- No paid news API is introduced.
